## 📌 Project Overview

This project analyzes Amazon Prime Video's content catalog using Tableau. It presents interactive dashboards to explore the distribution of movies and TV shows, ratings, release trends, runtime patterns, and relationships between content characteristics.

The goal is to transform raw content data into meaningful visual insights that can help users understand the platform's catalog and identify potential content trends.

## 🎯 Project Objectives

- Analyze the distribution of movies and TV shows.
- Understand content ratings and IMDb score patterns.
- Explore release-year trends.
- Examine runtime and popularity patterns.
- Compare movies and TV shows using interactive visualizations.
- Build an easy-to-use Tableau dashboard for data-driven exploration.

## 🛠️ Tools and Technologies

- **Tableau** — Interactive dashboards and visual analytics
- **Microsoft Excel / CSV** — Data inspection and preparation
- **Data Visualization** — Charts, KPI cards, scatter plots, and bubble charts
- **GitHub** — Project documentation and version control

## 📊 Dashboards

### 1. Overview Dashboard

Provides a high-level summary of the Amazon Prime Video catalog.

**Visualizations include:**
- Total Titles KPI
- Movie Share KPI
- Premium Content Percentage KPI
- High IMDb-Rated Content Percentage KPI
- Movie vs. TV Show distribution
- IMDb rating distribution
- Release-year trend
- Top actors by title count

### 2. Content and Ratings Dashboard

Explores content characteristics, ratings, runtime, and popularity.

**Visualizations include:**
- TMDb rating distribution
- Runtime distribution
- Average runtime by content type
- Top 10 popular titles
- Average rating by content type

### 3. Relationships and Talent Dashboard

Examines relationships between content attributes and ratings.

**Visualizations include:**
- Release Year vs. IMDb Score scatter plot
- IMDb rating distribution by content type
- Runtime vs. IMDb Score scatter plot
- Bubble chart for comparative analysis

## 📈 Key Insights

The following observations are based on the dashboard analysis and should be validated against the final workbook and dataset:

- Movies represent the majority of titles in the catalog.
- TV shows form a smaller share of the overall content library.
- Content runtime varies across titles and content types.
- Ratings differ across titles, suggesting varying audience reception.
- Release-year analysis helps identify changes in catalog composition over time.
- Scatter plots help explore potential relationships between runtime, release year, and IMDb scores.

## 💡 Business Recommendations

- **Content Strategy:** Monitor the balance between movies and TV shows to understand catalog coverage.
- **Content Quality:** Analyze highly rated titles to identify characteristics associated with stronger audience reception.
- **Catalog Planning:** Use release-year trends to understand the distribution of older and newer titles.
- **Audience Engagement:** Investigate popular titles and their ratings to identify content that attracts attention.
- **Data-Driven Decisions:** Use interactive filters and visual comparisons to explore content performance.
